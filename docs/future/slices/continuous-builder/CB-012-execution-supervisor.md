# CB-012 — Execution Supervisor

**Status:** Designing

## Purpose
Watch builders without micromanaging them.

## Intervene by exception
Step in on stalls, confidence collapse, new risk, requirement conflict, architecture impact, repeated failures, or scope escape.

## Failure behavior
When stuck: diagnose, summarize attempts, research alternatives, optionally consult another model/specialist, explain why attempts failed, recommend a new path and why it should work better.

## Acceptance
Healthy work proceeds quietly; abnormal work produces a bounded, evidence-backed escalation instead of endless retries.
