# CB-019 — Portfolio and Multi-Project Strategy

**Status:** Designing

## Purpose
Coordinate many projects as one MootOS ecosystem.

## Capabilities
Project health, strategic milestones, shared capability detection, cross-project dependencies, risk balancing, budget/resource forecasting, long-range roadmap simulation, compound-value scoring, and project retirement recommendations.

## Priority rule
Favor projects that unlock several future wins when justified. Protect focus from low-value shiny objects.

## Acceptance
Can explain the highest-value move across the portfolio and show downstream effects of changing project order.
