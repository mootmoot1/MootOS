# CB-010 — Rollback Framework and Drill

**Status:** Designing

## Purpose
Make reversibility a tested property rather than a promise.

## Track
Rollback method, data consequences, estimated time, prerequisites, whether tested, and confidence.

## Drill
Provide a disposable exercise that reverts a candidate slice and proves the documented path.

## Acceptance
For eligible changes, rollback can be demonstrated from evidence and failure to restore is itself a blocking finding.
