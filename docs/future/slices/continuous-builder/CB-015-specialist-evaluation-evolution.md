# CB-015 — Specialist Evaluation and Evolution

**Status:** Designing

## Purpose
Improve/replace specialist builders based on evidence rather than preference.

## Scorecards
Correctness, regression rate, scope discipline, speed, cost, test quality, review findings, retry count, maintainability.

## Upgrade flow
Benchmark new models/tools in safe tasks before promotion. Support promotion, demotion, replacement, or narrower specialization.

## Principle
Keep specialist interfaces provider-neutral.

## Acceptance
A model/tool swap requires comparative evidence and can be reversed without redesigning the Chief Builder.
