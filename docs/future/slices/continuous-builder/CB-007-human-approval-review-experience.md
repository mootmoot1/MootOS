# CB-007 — Human Approval and Review Experience

**Status:** Designing

## Purpose
Turn technical build output into a fast, useful decision for Moot.

## Review pack
- Why you should care.
- Short summary of changes.
- Risks and scope notes.
- Tests/evidence.
- How to test it manually.
- Rollback confidence and expected reversal time.
- Recommendation: approve, hold, or request changes, with why.

## UI principle
No raw code dump by default. Raw diff remains available on demand.

## Acceptance
A reviewer can understand the user impact, risk, evidence, and test path without reading source code first.
