# CB-013 — Build Progress Intelligence

**Status:** Designing

## Purpose
Provide useful progress signals without chatty status spam.

## Track
Current phase, milestones complete/remaining, stall duration, ETA range, resource usage, confidence trend, and build-health score.

## Notification rule
Log normal progress silently. Notify Moot for meaningful milestones, blockers, serious risk, or unusually important discoveries.

## Acceptance
Progress estimates expose uncertainty and stale/stuck work is detected reliably.
