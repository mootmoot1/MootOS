# CB-004 — Priority Engine

**Status:** Designing

## Purpose
Rank Ready work by value instead of list order.

## Signals
Impact, urgency, dependency leverage, compound capability value, risk, confidence, effort/cost, user value, revenue potential, time saved, architecture leverage, current focus.

## Product rule
Bias to high-impact/high-leverage foundations first. Once major foundational work is roughly 35–50% established, mix in high-value quick wins for momentum.

## Acceptance
Returns ranked candidates with plain-English rationale and does not rank blocked work as executable.
