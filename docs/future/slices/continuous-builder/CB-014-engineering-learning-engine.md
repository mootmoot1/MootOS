# CB-014 — Engineering Learning Engine

**Status:** Designing

## Purpose
Maintain both full build history and a distilled living engineering playbook.

## Learn
Recurring bugs, successful patterns, failed approaches, test gaps, architectural pain, useful libraries/tools, worker weaknesses, and confidence calibration.

## Rules
Raw history is immutable evidence; the playbook is a derived, versioned guide that may evolve.

## Acceptance
Future builders can retrieve relevant proven lessons and confidence estimates become better calibrated against actual outcomes.
