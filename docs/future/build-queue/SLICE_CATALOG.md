## Materialization rule

The first 20 Continuous Builder slices have individual seed specs under `../slices/continuous-builder/`. The remaining catalog entries should be turned into individual implementation specs only after dependency/current-code analysis, rather than fabricating exact file paths or interfaces years early. The Continuous Builder's future Spec-to-Slices Pipeline should automate that materialization while preserving human approval for architecture changes.
